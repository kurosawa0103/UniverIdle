# 设计总览

> 状态：**进行中** · 最后更新：2026-09-01

## 项目简介

**UniverIdle**（宇宙无敌放置游戏）是一款类似 [Melvor Idle](https://melvoridle.com/) 的挂机增量游戏，使用 **Unity** 开发。

**题材**：剑与魔法异世界为主，宇宙/多位面要素作背景点缀（「Univer」体现在无尽大陆与位面之外，而非星际科幻）。

当前工程已有 **主界面 UGUI**（Editor 一键生成、技能/动作占位交互），尚无挂机循环、存档与伐木玩法数据。

## 世界观基调（已确认）

| 层次 | 权重 | 设定方向 |
|------|------|----------|
| **剑与魔法主舞台** | 主 | 大陆、王国、地下城、魔法、怪物、锻造、炼金、冒险成长 |
| **宇宙 / 位面背景** | 点缀 | 坠星、异界裂隙、虚空边缘、天界遗迹；用魔法 lore 解释，非科幻 |

玩家体感：**奇幻放置 RPG**（气质接近 Melvor），宇宙感通过稀有素材、后期区域、世界观条目慢慢渗透，而非满屏星舰与终端。

主角身份、叙述方案等待 [题材呈现与世界观](06-题材呈现与世界观.md) 定稿。

## 参考作品：Melvor Idle

Melvor Idle 的核心体验不是画面，而是 **多技能协作 + 资源链 + 长期成长**：

| 维度 | Melvor 的做法 |
|------|---------------|
| 交互 | 点选动作 → 等待完成 → 获得资源/经验 |
| 成长 | 多技能树互相依赖（采矿 → 锻造 → 战斗） |
| 节奏 | 挂机 + 离线收益 + 长期目标（地牢、装备、精通） |
| 呈现 | 以 UI/文字为主，战斗为数值结算 |

## 设计原则

1. **借鉴 Melvor 核心，奇幻气质为主** — 技能链与挂机节奏保留；宇宙要素作点缀与后期扩展
2. **MVP 优先** — 第一版追求可玩闭环，而非功能对标完整 Melvor
3. **数据驱动** — 技能、物品、配方等尽量配置化，便于迭代平衡
4. **UI 为主** — 战斗与生产均以界面交互为核心，不做动作类玩法
