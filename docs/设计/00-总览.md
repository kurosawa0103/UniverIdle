## 设计原则（摘要）

1. **和 Melvor 一样简单** — 点动作、等条、拿东西；不加远征/据点/学徒
2. **奇幻为主** — 剑魔法地下城；星尘/坠星作稀有层，不做科幻主线
3. **具体名词** — 萤虾、星沙、坠星坑；拒绝抽象「权限/勘验」壳
4. **MVP 优先** — 先跑通一条产线（虾→药→狼），再扩区域
5. **PC 先** — 玩法与 UI 分离，二期再适配手机
