# UI 视觉风格

> 状态：**草案 v2** · 最后更新：2026-09-01

**只改界面，不改玩法**（左工作栏 + 右动作 + 挂机）。结构见 [核心玩法](08-核心玩法.md)。

---

## 方向（当前）

| 要 | 不要 |
|----|------|
| **有图** — 技能图标、地点插图、物品图、动作缩略图 | 纯文字 + 极简留白 |
| **交互舒服** — 大点击区、状态清晰、少误触 | 为了好看牺牲可用性 |
| **排版合理** — 分区明确、视线有主次 | 信息堆一坨或太空 |
| 奇幻插画感、温暖耐看 | 极简手绘线稿风（已废止） |
| 手绘/插画 **作点缀**，不是唯一视觉 | 厚重网游金光 UI |

---

## 视觉气质

- **风格**：2D 奇幻插画 UI — 偏 Melvor 的信息密度，但 **每块都有图**（类似带立绘/场景的放置页游）
- **色调**：暖褐木框 + 深青绿/琥珀点缀 + 奶油底（坠星谷夜晚微光感）
- **材质**：轻木框、纸卡、柔和阴影；按钮有按下态
- **字体**：标题圆润衬线或柔和黑体；正文 14～15px，行高 ≥ 1.5

### 各区域职责

| 区域 | 宽度/高度 | 内容 | 交互 |
|------|-----------|------|------|
| **顶栏** | 全宽 56px | 地名、货币、全局入口 | 图鉴/背包/设置 |
| **左技能导航** | 168px | 图标+名+等级条；当前高亮 | 单击切换；可滚动 |
| **地点横幅** | 主区顶 140px | **场景插画** + 地名 + 天气/危险标签 | 可点换地点（子页签） |
| **动作卡片区** | 主区中 | **卡片网格** 2～3 列；每卡：缩略图、名、耗时、产出图标 | 单击开始；已锁定灰显 |
| **进行中条** | 主区底 | 大进度条 + 当前动作图 + 下次掉落提示 | 可点取消/切换 |
| **右侧栏** | 220px 可折叠 | 选中动作的大图、描述、需求材料 | 减少主区拥挤 |
| **底物品栏** | 全宽 72px | **物品图标** + 数量；横滑 | 单击查看详情 |

## 交互规范（舒服优先）

| 规则 | 数值/说明 |
|------|-----------|
| 可点击最小高度 | ≥ 44px（动作卡 ≥ 72px） |
| 技能项间距 | 8px；选中左边色条 4px |
| 悬停 | 卡片轻抬升 + 边框高亮 |
| 选中 | 背景变亮 + 描边；进行中额外脉冲光圈 |
| 锁定 | 灰度 + 锁图标；悬停显示解锁条件 |
| 反馈 | 完成动作时图标弹跳 + 飘字 `+1 萤虾` |
| 误触防护 | 取消挂机需二次确认或长按 |

## 图片资源清单（Unity 需美术）

| 类型 | 数量（MVP估） | 用途 |
|------|---------------|------|
| 技能图标 | 7 | 左栏 |
| 地点横幅 | 5～8 | 萤溪、矮洞、林缘… |
| 动作缩略图 | 30～50 | 动作卡片 |
| 物品图标 | 40～80 | 底栏、配方 |
| 怪物/敌人图 | 10～20 | 讨伐、图鉴 |
| UI 框/按钮 | 1 套九宫格 | 面板底图 |

占位阶段可用 **色块+剪影**；正式用统一尺寸的 PNG（建议 128 物品、256 横幅、64 技能）。

## 与 Melvor 对比

| | Melvor | UniverIdle UI |
|--|--------|---------------|
| 结构 | 左技能列表 | **相同** |
| 视觉 | 偏扁平图标 | **插画+卡片+场景横幅** |
| 动作行 | 文字列表 | **带图的卡片** |
| 物品 | 背包页 | **底栏常驻图标条** + 背包 |
| 极简 | — | **不做** |
