# 核心玩法

> 状态：**草案 v3（简化）** · 最后更新：2026-09-01

## 设计原则：和 Melvor 一样简单

| 要 | 不要（v2 已砍） |
|----|----------------|
| 点一个动作，等条走完，拿东西 | 远征行囊配包 |
| 想换活就换另一个动作 | 地图节点 + 学徒派遣 + 建筑队列三套并行 |
| 缺料就去另一项工作挂一会儿 | 升级建筑、修节点、声望 |
| 上线收菜，离线继续 | 复杂成功率、多进度条管理 |

**差异化放在**：坠星谷题材、物品名、区域故事、一条星尘贯穿配方 — **不是加新系统**。

---

## 一句话

**侧边栏选一项工作 → 选具体活 → 挂机 → 材料够了换下一项。**

和 Melvor 相同的心智负担。

---

## 单局循环（30 秒）

```
打开工作列表 → 点「萤溪 · 钓萤虾」→ 等 8 秒 → +1 虾
虾够了 → 点「炼药 · 熬红药」→ 等 → +1 药
药够了 → 点「讨伐 · 林缘杀狼」→ 等 → 掉皮、经验
```

没有第三层界面，没有打包出门。

---

## 成长三阶段

### 先做什么（0～1 小时）

| 顺序 | 内容 |
|------|------|
| 1 | 最弱的活：打耗子、钓萤虾、淘星沙 |
| 2 | 发现：虾和苔能熬药 |
| 3 | 带着药去打稍强的怪 |
| 4 | 掉落让你能开新动作（铜矿、狼皮） |

学会：**A 的产物是 B 的原料** — 就这一条。

### 再做什么（几小时～）

- 工作列表变长（多几个地点、多几种活）
- 新区域要 **等级或前置掉落** 才进得去
- 偶尔缺料，切回去补几条挂机

### 最后追求什么

- 打进坠星坑深处 / 杀龙 / 钓赤尾鳗
- 工作练满、装备做好、图鉴填满
- 宇宙相关只在 **最后几个区域和稀有配方**

## 工作列表（= Melvor 技能栏）

左栏列出全部工作，**数量不因 UI 改版而减少**。动作名建议带地名。

| 工作 | 低级动作 | 高级动作（后期） |
|------|----------|------------------|
| **打猎** | 谷仓 · 赶耗子 | 狼 → 星蚀兽 → 龙 |
| **伐木** | 村外 · 砍枯枝 | 黑林 · 伐橡木 → 逆光木 |
| **溪钓** | 萤溪 · 钓萤虾 | 鳟鱼 → 坑底 · 赤尾鳗 |
| **野拾** | 萤苔、淘星沙 | 逆光木 |
| **掘矿** | 矮洞 · 挖铜 | 温铁、星髓 |
| **炼药** | 红药水 | 抗热药 |
| **锻造** | 铜刀、皮甲 | 传说装 |
| **讨伐** | 林缘 | 坠星坑、龙窟 |

**串联范例**（和 Melvor 一样自然）：

```
钓虾 + 割苔 → 熬药 → 讨伐林缘 → 掉皮 → 锻造护甲 → 进更深区域
```

## 和 Melvor 怎么区分（轻量）

| 维度 | Melvor | 我们 |
|------|--------|------|
| **操作** | 一样简单 | 一样简单 |
| **结构** | 技能 + 动作 | 一样 |
| **题材** | 奇幻大陆 | **坠星谷**（一颗星砸出的谷） |
| **区域** | 很多分散地点 | **一条线往坑里走**（萤溪→林→坑） |
| **贯穿物** | 各种独立材料 | **星沙/星尘** 多配方都要一点（味道，不加机制） |
| **文案** | 百科 | 万物图鉴 + 可选手账 |

**不做**：当铺、管理局、远征整备、学徒、建筑升级。
