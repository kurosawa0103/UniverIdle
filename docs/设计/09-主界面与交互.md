## 三区 + 底栏（合理排版）

1. **左**：技能导航（图+名+等级）— 固定宽，可滚动  
2. **中**：地点横幅图 → 动作卡片网格 → 大进度条  
3. **右**：选中动作详情（大图、说明、材料需求）— 可折叠  
4. **底**：物品图标横条 — 常驻可见  

不是极简线稿；每个可点区域都有 **图像锚点**，减少纯文字扫读疲劳。

---

## 核心交互流

```
点左栏「溪钓」→ 中上显示萤溪横幅 → 点卡片「钓萤虾」→ 中大进度条跑条 → 底栏虾+1
```

切换技能：左栏一点，中间 **整块换区**（横幅+卡片+进度），右侧详情同步更新。
