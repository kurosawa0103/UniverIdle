## 布局（PC）

```
顶栏：Logo / 地名 / 金币·声望 / 图鉴·背包·设置
├ 左 172px   技能导航（图+名+等级，可滚动）
├ 中 弹性     地点横幅 → 动作卡片 → 进行中大进度条
├ 右 228px   选中动作详情（可折叠）
└ 底 76px    物品图标横条
```

应用面板 **铺满画布**（随窗口缩放），Canvas 参考 1920×1080。

## 交互流

```
点「溪钓」→ 中上萤溪横幅 → 点「钓萤虾」→ 进度条跑条 → 底栏虾+1
```

切换工作：左栏一点，中间整块换区（横幅+卡片+进度），右侧详情同步。

| 规则 | 说明 |
|------|------|
| 点击区 | 动作卡 ≥ 72px 高 |
| 选中 | 左色条 + 背景高亮；进行中可加脉冲 |
| 锁定 | 灰显 + 悬停显示条件 |
| 完成 | 图标弹跳 + 飘字 `+1 萤虾` |
| 取消挂机 | 二次确认或长按 |
