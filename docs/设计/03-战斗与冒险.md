# 战斗与冒险

> 状态：**未开始**

## 题材约束（已确认）

战斗区域与敌人以 **经典奇幻** 为主：森林、矿洞、地下城、沼泽、遗迹。宇宙点缀区域（坠星坑、虚空裂隙）作为 **后期或支线**，MVP 可不做。

## 待讨论内容

- 战斗是否回合制 / 攻速计时 / 纯数值结算
- MVP 区域：建议 1 个经典奇幻区（如「低语森林」或「废弃矿道」）
- 敌人：哥布林、狼、骷髅、史莱姆等；后期可加「异界侵蚀种」「坠星畸变体」
- 死亡、食物、药水等生存机制是否保留（Melvor 有）
- 装备槽位与属性体系（物理 / 魔法分轨即可，避免「星术」抢戏）
- 掉落表与难度曲线

## 区域分层草案（占位）

| 层级 | 示例 | 何时引入 |
|------|------|----------|
| **主线奇幻** | 迷雾森林、哥布林洞穴、古代地下城 | MVP |
| **进阶奇幻** | 龙巢边缘、死灵遗迹、深暗地域 | 首版后扩展 |
| **宇宙点缀** | 坠星坑、虚空裂隙、天界残骸 | 后期 / 稀有副本 |
