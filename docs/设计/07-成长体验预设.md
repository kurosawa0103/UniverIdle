# 成长体验预设

> 状态：**草案** · 最后更新：2026-09-01

## 设计目标

参考 Melvor（农场杀鸡）、银河奶牛类放置（苍蝇 → 虾米 → 鲸鱼）的 **落差感**：

1. **开局很怂** — 玩家会笑、会觉得自己弱
2. **中期有盼头** — 解锁新区域、新配方，明显变强
3. **后期很狂** — 做早期想都不敢想的事（屠龙、熔岩钓巨兽、砍魔法树）
4. **宇宙点缀在最后** — 奇幻主线跑通后，才碰「坠星」「虚空」等离谱层

玩家应能一句话概括自己的旅程（具体文案随所选方案变化）。

---

## 为何「村口史莱姆 + 采矿钓鱼」太像 Melvor

| Melvor 标志性结构 | 我们草案里撞车的部分 |
|-------------------|---------------------|
| 分技能采集（矿/木/鱼） | 采矿、伐木、钓鱼并列 |
| 新手村 → 森林 → 地下城 | 落叶村 → 低语森林 → 矿道 |
| 战斗独立成线，装备驱动 | 同款 |
| 奇幻百科条目 | 可保留（不算抄袭） |

**要换的**：**开场地点、第一件具体的事** — 玩家 3 秒内能想象画面。  
**不要**：管理局、权限档、尺度膨胀等 **一听要解释的抽象壳**。

---

## 设计铁律：具体 > 概念

| 好（具体） | 不好（抽象） |
|------------|--------------|
| 剥史莱姆黏靴、淘星沙、钓萤虾 | 勘验现场、净化诅咒物 |
| 地下城第 2 层打蝙蝠 | 镇厄失控咒物 |
| 熔岩河里钓火鳗 | 权限升到 S 档 |
| 坠星坑边砍会发光的树 | 尺度从微苑升到大陆 |

玩家应能 **指着屏幕说清楚**：「我在干嘛。」

## 方案 A：地下城门口镇「回炉镇」

### 画面（3 秒能懂）

镇上最大的建筑是 **地下城入口**。冒险者每天进出，你一开始 **在镇上过活** — 不是农场杀鸡，是 **吃地下城剩饭**。

### 开局在干嘛（又怂又具体）

| 动作 | 产出 | 像什么 |
|------|------|--------|
| 剥冒险者靴底史莱姆胶 | 黏液、皮屑 | 银河奶牛拍苍蝇 |
| 把断剑扔进回炉炉 | 废铁锭 | 收破烂 |
| 晒蝙蝠翅膀（冒险者不要的） | 干翅膀 | 加工边角料 |
| 镇口杀 **下水道耗子** | 鼠尾 | Melvor 杀鸡（但场景不同） |
| 给新手冒险者 **熬劣质红药水** | 药水卖钱 | 第一笔正经收入 |

**地点**：回炉镇广场、公会后门、下水道入口 — 全在镇上，**不用先下地下城**。

### 成长后（同一条镇，活动变猛）

| 阶段 | 你在干嘛 |
|------|----------|
| 镇上杂活 | 上面那些 |
| **地下城 1～3 层** | 自己杀史莱姆、蝙蝠，捡蘑菇、铜矿 |
| **10 层以后** | 火堆旁 **钓熔岩火鳗**、杀兽人、捡秘银 |
| **深层** | **龙窟外环**捡鳞片、参与屠龙队后勤（熬大师药水） |
| 点缀 | 地下城最深处有一间 **星陨密室**（宇宙相关，就一间屋） |

### 技能（名字直白）

| 技能 | 干什么 |
|------|--------|
| **打理** | 镇上加工：剥胶、晒翅膀、回炉废铁 |
| **下本** | 进地下城某层挂机战斗+采集 |
| **打铁** | 武器护甲 |
| **熬药** | 药水 |

没有「钓鱼技能」— 熔岩火鳗是 **下本到熔岩河层** 的动作，和「在第 7 层钓鱼」绑定，好懂。

### 一句话

> 「起初给冒险者剥靴子上的史莱姆；后来在龙窟门口熬能让全队扛喷火的药。」

### 和 Melvor 差在哪

- 开场是 **地下城经济下游**，不是农场  
- 地图是 **一座镇 + 一座地下城往下走**，不是大陆到处跑  
- 宇宙只藏在 **最深层一间星陨室**，不抢戏

## 方案 B：坠星谷「萤溪村」（推荐 · 扣题又具体）

### 画面（3 秒能懂）

几百年前 **一颗星星掉进山谷**，砸出大坑；村子在坑边，溪水夜里会发微光。  
你知道三个地名就行：**村口、萤溪、坠星坑**。

### 开局在干嘛

| 动作 | 地点 | 产出 |
|------|------|------|
| 打 **谷仓耗子** | 村口粮仓 | 鼠尾、破布 |
| **淘星沙** | 萤溪浅滩 | 星沙（像淘金，手伸水里） |
| **钓萤虾** | 萤溪 | 萤虾（小虾米，会发光） |
| 割 **溪边萤苔** | 萤溪岸 | 萤苔（当药草用） |
| 挖 **坡面铜矿** | 村后矮洞 | 铜矿 |

全是 **看得见的名词**：耗子、星沙、萤虾、苔、铜矿。  
不用解释什么是「勘验」「权限」。

### 成长后

| 阶段 | 地点 | 在干嘛 |
|------|------|--------|
| 村里 | 萤溪、矮洞 | 上面那些 |
| 出村 | **黑松林** | 猎狼、采松脂、伐橡木 |
| 进山 | **坠星坑外圈** | 挖 **温铁**（摸着发烫的矿）、杀 **星蚀狼** |
| 进坑 | **坠星坑深处** | 杀 **守坑兽**、砍 **逆光木**（坑边长的发光树） |
| 坑底 | **星髓熔潭** | **钓赤尾鳗**（在烫人的潭子里，具体的一条鱼） |
| 终局 | 坑底裂隙 | 杀 **古龙幼体** 或 **星骸守卫**（奇幻 BOSS，不是飞船） |

「宇宙」= **天上掉下来的那颗星星**，玩家从小就听老人讲，后期终于走进坑底 — 不是抽象位面。

### 技能（名字直白）

| 技能 | 干什么 |
|------|--------|
| **打猎** | 耗子 → 狼 → 星蚀兽 → 龙 |
| **野拾** | 淘星沙、割苔、伐木（按地点换动作名，技能栏还是一个） |
| **掘矿** | 铜 → 铁 → 温铁 → 星髓矿 |
| **溪钓** | 萤虾 → 鳟鱼 → **赤尾鳗（坑底熔潭）** |
| **打铁 / 熬药** | 装备药水 |

比 Melvor 少一门「纯钓鱼贯穿全世界」，但 **萤虾 → 赤尾鳗** 的落差还在，而且和 **坠星坑** 绑死，有记忆点。

### 一句话

> 「小时候在萤溪淘星沙、钓小虾；后来在坠星坑底的烫潭里钓赤尾鳗。」

### 和 Melvor 差在哪

- **一张主地图**：谷 → 林 → 坑，往下/往里走，不是散装新手村  
- 宇宙 = **那颗坠星**，小孩都懂  
- 物品名接地气：星沙、萤虾、温铁，不是星域勘探报告

## 方案 C：碎岛链「从礁滩开始」

### 画面

你困在 **最小的一块礁滩** 上，能看见远处更大的岛。成长 = **造筏 → 登下一岛 → 再下一岛**。

### 开局

| 动作 | 产出 |
|------|------|
| 砸 **滩蟹** | 蟹肉、蟹壳 |
| 捡 **漂流木** | 木料 |
| 挖 **咸水洼里的蛤蜊** | 蛤蜊肉 |
| 织 **草绳**（用海草） | 造筏材料 |

### 后期岛（举例，一座岛一个主题）

| 岛 | 在干嘛 |
|----|--------|
| 第二岛 | 杀野猪、采野矿 |
| 第五岛 | 迷雾林、哥布林 |
| 第十岛 | 火山岛、熔岩钓 **烟鳞鱼** |
| 终岛 | 大陆边岸 / 海沟钓 **裂渊鲸** |

### 一句话

> 「第一天只有螃蟹和漂流木；后来我在火山岛烫脚的水里钓鱼。」

### 优点

地图进度 **一眼看懂**（岛链图）。  
### 缺点

和不少生存/放置游戏撞「跳岛」；奇幻味要靠自己堆。

## 综合推荐（具体 + 不太像 Melvor）

| 优先 | 选 | 理由 |
|------|-----|------|
| **首推** | **B 坠星谷** | 具体好懂；萤虾→赤尾鳗；宇宙 = 坠星，不抽象；和 Melvor 的「散装大陆」不同 |
| 次选 | **A 回炉镇** | 开场最不像 Melvor（吃地下城剩饭）；适合最爱地牢的人 |
| 再次 | **C 碎岛链** | 最直观，但奇幻+宇宙感要弱一点 |

**建议 MVP（以坠星谷为例）**：  
萤溪村全流程（耗子、星沙、萤虾、铜矿）→ 解锁黑松林 → 钩子：「坠星坑外圈有人看见狼眼睛发红。」

## 方案 I：禁忌物勘验师（已降权 · 偏抽象）

### 核心想法

你不是来「当冒险者」的，你是 **王国禁忌物管理局编外学徒**（或破产调查所实习生）。  
开局干的是：**勘验、净化、封存** 别人不敢碰的破烂；后期才亲手处理 **古龙遗骸、灭世级咒物、坠星核心**。

**和 Melvor 的分水岭**：没有「钓鱼技能」「伐木技能」；采集统一成 **「勘验现场」** — 去哪、带什么工具、净化等级多少，决定掉什么。

### 体验曲线

| 阶段 | 你在干嘛 | 对标「苍蝇→鲸鱼」 |
|------|----------|-------------------|
| **实习** | 勘验酒馆霉斑、净化诅咒铜币、封存「疑似龙牙」（其实是狗牙） | 苍蝇、虾米 |
| **外勤** | 进废弃庄园封存怨念镜、净化哥布林营地污染源 | 杀鸡、砍小树 |
| **专员** | 地下城核心咒物定点封存、调和镇魔剂支撑讨伐队 | 中级地下城 |
| **大师** | 参与 **古龙遗骸分检**、熔岩海捞取「未冷却龙心」、砍伐 **咒化世界树心材** | 钓鲸鱼、砍魔法树、杀龙 |
| **署长级** | 封存 **坠星核心**、虚空裂隙守门遗物（宇宙点缀） | 终局 |

### 技能结构（5 条，非 Melvor 式五采集）

| 技能 | 职能 |
|------|------|
| **勘验** | 前往地点「作业」，产出原材料（按区域变，不是按技能变） |
| **净化** | 加工诅咒物、提取净材 |
| **封存** | 制造容器、护符、封印匣（= 装备/道具） |
| **调和** | 药水、镇魔剂、讨伐队补给 |
| **镇厄** | 战斗 — 专门对付「失控咒物/怪物」，不是普通砍哥布林 |

### 一句话旅程

> 「第 1 天：鉴定一块会打喷嚏的抹布。第 200 天：给灭世龙心办入库手续。」

### 优点

- 奇幻味正，宇宙点缀自然落在「禁忌分级」最高档  
- 图鉴 = **危险物登记册**，和 Melvor 物品百科气质像但 **身份完全不同**  
- 技能少而清晰，适合 MVP

## 方案 II：位面当铺（经济收藏派 · 最不像 Melvor）

### 核心想法

你经营一家 **开在异世界街角、连通多位面的当铺**。  
开局 **收破烂、鉴定、翻新、倒卖**；后期 **陈列传说异物、委托跨位面回收、护送天价货**。

战斗不是主线，是 **「送货路上」「讨债」「劫匪盯上藏品」**；成长爽点是 **账本数字和货架格子**。

### 体验曲线

| 阶段 | 你在干嘛 |
|------|----------|
| **学徒** | 5 铜币收生锈菜刀、鉴定真假魔杖（大部分是树枝） |
| **掌柜** | 低语森林猎人的兽皮抵债、地下城退下来的「沾血盔甲」 |
| **名店** | 竞拍龙鳞（残片）、熔岩海「赤渊鲸油」瓶（未开封） |
| **传说** | 货架陈列 **单向诅咒王冠**；接委托去 **古龙巢穴取回当票物品** |
| **位面总行** | 回收 **坠星碎片**、虚空夹缝里的「不存在之物」 |

### 技能结构

| 技能 | 职能 |
|------|------|
| **收购** | 挂机「蹲点收货」— 区域决定来什么货 |
| **鉴定** | 解锁真实属性、去赝品 |
| **修复** | 翻新卖更高价 / 自用 |
| **陈列** | 被动加成（客流、声望、挂机效率）— 类似 mastery 的另一种味道 |
| **护送** | 战斗技能，保卫高价值运输 |

### 一句话旅程

> 「第 1 天：收了一块会骂人的抹布。第 200 天：龙来赎它当掉的鳞片。」

### 优点

- **和 Melvor 玩法重心最不同**（经营 > 自给自足采集）  
- 「宇宙无敌」可做成 **位面总行头衔** 或 **坏账终于清完**  
- 梗多、适合手账叙述  

### 缺点

- 需要把 **经济循环设计清楚**（现金流、囤货、物价），平衡难度高于方案 I  
- 不爱经营的玩家可能 miss「战斗爽」

## 方案 III：尺度膨胀（同一世界，越变越大）

### 核心想法

始终在同一个「Univer」世界里，但 **挂机尺度层层放大** — 不是换地图而已，是 **你连敌人是谁都变了**。

| 尺度 | 你在干嘛 | 敌人/资源 |
|------|----------|-----------|
| **微苑** | 帮花园妖精灭蚜、给苔藓松土 | 蚜虫、露水是「巨湖」 |
| **乡里** | 猎狼、采矿、常规奇幻 | 经典 RPG |
| **王国** | 讨伐军团、矿脉国策 | 战争级资源 |
| **大陆** | 猎古龙、熔岩海钓鲸、砍咒化森林 | 传说级 |
| **星穹** | 猎星座、收坠星（点缀层） | 宇宙级 |

### 和 Melvor 的差异

- 前期 **不是杀鸡是灭蚜** — 落差更荒诞（「宇宙无敌」从帮虫子开始）  
- **同一技能名**（如「征讨」），在不同尺度描述和产出完全不同 — 系统感强  
- UI 可暗示「当前尺度：微苑 → 乡里」  

### 一句话旅程

> 「我曾为一只蚜虫忙一下午；后来大陆叫我一声大人。」

### 优点

- 完美扣题 **Univer（无穷尺度）**  
- 保留战斗+采集双线，但包装新鲜  

### 缺点

- 数值与文案都要做 **尺度切换规则**，设计量偏大  
- 中后期仍可能滑向 Melvor 式区域列表

## 方案 IV：无敌权限错登（梗与 meta 派）

### 核心想法

穿越时 **神之系统错把你登记为「宇宙无敌」**，但当前只解锁 **F 级权限**：除尘、驱鼠、拧瓶盖。  
升级 = **解锁更高权限档**，不是传统冒险者晋级。

| 权限档 | 能做的事 |
|--------|----------|
| F | 除尘、赶鼠、净化霉斑 |
| E～C | 常规冒险者能力（借系统之名解锁） |
| B～A | 屠龙、熔岩钓鲸等「申请已批准」 |
| S | 宇宙无敌（名实相符） |

### 优点

- 「宇宙无敌」梗 **从第一天就成立**  
- 和 Melvor 的「朴素奇幻」气质反差大  

### 缺点

- 全文案要带系统感，和「纯奇幻百科」略冲突（可做成 **神谕石板** 奇幻化 UI）  
- 容易写成泛滥的异世界系统文

**个人首推：方案 I**，或 **I + 少量 IV**（管理局给你误发了「无敌」工牌，其实仍是实习生）。

## 方案 0：经典冒险者线（偏 Melvor，备选）

> 以下为初版草案，因结构过近 Melvor 已 **降权为备选**；若选方案 I～IV，本节仅作区域/落差参考。

### 第一幕：村口废物（0～30 分钟）

**地点**：落叶村及周边 — 新手村、农田、臭水沟、村口矮矿脉  

**玩家在干嘛**（又菜又真实）：

| 技能 | 低级动作 | 产出 | 文案气质 |
|------|----------|------|----------|
| 战斗 | 驱赶田鼠、戳史莱姆、揍醉汉哥布林 | 鼠尾、黏液、破布 | 「村卫队都不愿接这活。」 |
| 伐木 | 砍枯枝、削灌木 | 短木、树皮 | 工具：生锈手斧 |
| 采矿 | 刨村口页岩、挖露天铜斑 | 铜砂、碎石 | 「这也能算采矿？」 |
| 钓鱼 | 村边臭水沟钓泥鳅 | 泥鳅、小虾 | 「建议洗完手再吃饭。」 |
| 草药 | 拔蒲公英、捡蘑菇（别吃红的） | 野草、普通蘑菇 | 炼金前置 |

**装备**：木棍、布衣、草鞋。  
**体感**：搞笑、卑微、但 **立刻有挂机反馈**（和经验条在涨）。

> MVP 建议：**至少覆盖战斗 + 1 条生产链（采矿或伐木）+ 钓鱼或草药二选一**，让玩家在第一幕就感到「多条线可以挂」。

---

### 第二幕：冒险者出道（数小时）

**地点**：低语森林、废弃矿道、浅溪  

**解锁感**：第一次离开村子，怪物像「正经 RPG」了。

| 技能 | 升级动作 | 新产出 |
|------|----------|--------|
| 战斗 | 猎狼、清哥布林哨所、进小型洞穴 | 狼皮、哥布林牙、铜币 |
| 伐木 | 伐橡木、采树脂 | 橡木、松脂 |
| 采矿 | 铜矿、锡矿正式矿脉 | 铜锭、锡锭（需冶炼） |
| 钓鱼 | 溪钓鳟鱼、泥鳅升级饵 | 鳟鱼、贝壳 |
| 锻造 | 铜短剑、皮甲、铁镐升级 | 第一件「像样」的装备 |
| 炼金 | 小型治疗药水、力量药水 | 战斗续航 |

**关键里程碑**：

- 第一次穿上 **非布衣** 护甲
- 第一次 **药水挂机战斗** 不饿死
- 第一次 **配方需要跨技能**（矿 → 锭 → 剑）

**体感**：从「村里杂活」变成「冒险者日常」。

---

### 第三幕：大陆有名（数十小时）

**地点**：黑铁地下城、迷雾沼泽、海岸礁石、深林秘境  

| 技能 | 中级动作 | 新产出 |
|------|----------|--------|
| 战斗 | 亡灵矿道、沼泽毒蛙、海盗残骸 | 秘银碎片、毒囊、稀有宝石 |
| 伐木 | **魔法树苗**（低阶）— 需附魔斧 | 魔力木芯、树妖汁液 |
| 采矿 | 铁矿、秘银、深层煤矿 | 钢锭、秘银锭 |
| 钓鱼 | 礁石钓章鱼、夜钓发光鱼 | 稀有鱼油（炼金） |
| 锻造 | 钢剑、秘银甲、附魔槽位 | 可附魔装备 |
| 炼金 | 高级药水、爆炸瓶、附魔油 | 支撑高压区域 |

**关键里程碑**：

- 第一次砍 **「会发光的树」**（魔法树入门）
- 第一次 **地下城多层挂机**
- 装备从「能用」到「配装」

**体感**：Melvor 中期的爽点 — **专精一条线也能变强，但跨技能更猛**。

---

### 第四幕：传说级（后期主内容）

**地点**：龙息峡谷、熔岩海、极寒深渊、古代巨人遗迹  

**玩家在干嘛**（和开局反差拉满）：

| 技能 | 高级动作 | 爽点 |
|------|----------|------|
| 战斗 | **屠龙**、深渊领主、古龙幼崽巢穴 | 龙鳞、龙心、传说掉落 |
| 伐木 | **世界树幼枝**、诅咒古木、魔法森林核心 | 顶级法杖/弓材 |
| 采矿 | 精金、龙晶矿、地心矿脉 | 传说武器坯 |
| 钓鱼 | **熔岩海钓岩浆鲸**、冰海钓利维坦幼体 | 离谱食材/炼金触媒 |
| 锻造 | 传说武器、套装、大师附魔 | 数值质变 |
| 炼金 | 传说药水、战斗变身剂 | 终局战斗辅助 |

**文案示例**（图鉴条目）：

> **〔熔岩海 · 赤渊鲸〕**  
> 类别：传说渔获  
> 需在岩浆温度区间内保持钓线完整。落叶村那位教你钓泥鳅的老人不会相信这种事。

**体感**：和第一幕形成 **梗式对比** — 玩家愿意截图发朋友圈。

---

### 第五幕：位面之外（宇宙点缀 · 可选终局）

**地点**：坠星坑、虚空裂隙边缘、天界残骸（**不是科幻主线，是奇幻里的「禁区」**）  

| 内容 | 说明 |
|------|------|
| 战斗 | 坠星畸变体、虚空侵蚀的古龙、异界守门人 |
| 采集 | 星尘铁、虚空碎片、天界余烬 |
| 制造 | 星尘附魔、位面钥匙、终极饰品 |
| 叙事 | 解释「星空之外还有什么」— 一两句话就够，不抢龙和熔岩鲸的风头 |

**体感**：给硬核玩家 **最后 5% 的离谱**；普通玩家第四幕已够爽。

## 技能解锁节奏（草案）

不必开局开放全部技能；用 **解锁顺序** 强化成长感：

```
开局：战斗、伐木、钓鱼（或草药）
  ↓ 离开村子
采矿、冶炼（或锻造前置）
  ↓ 第一件铜装备
锻造
  ↓ 第一次地下城压力
炼金
  ↓ 中期区域
附魔 / 高级配方
  ↓ 传说区域门槛
终局技能动作（熔岩钓、屠龙等）
  ↓ 可选
坠星 / 虚空区域（宇宙点缀）
```
