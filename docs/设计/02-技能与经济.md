## 工作列表（坠星谷草案）

| 工作 | 动作示例 | 产出喂给 |
|------|----------|----------|
| 打猎 | 赶耗子 → 猎狼 | 皮、肉 → 锻造、炼药 |
| **伐木** | 村外 · 砍枯枝 → 黑林 · 伐橡木 | 原木、木炭 → 锻造、炼药 |
| 溪钓 | 萤虾 → 赤尾鳗 | 虾 → 炼药 |
| 野拾 | 萤苔、星沙 | 炼药、锻造 |
| 掘矿 | 铜矿 → 温铁 | 锻造 |
| 炼药 | 红药、抗热药 | 讨伐 |
| 锻造 | 铜刀、皮甲 | 讨伐 |
| 讨伐 | 林缘 → 坠星坑 | 掉落 → 各链 |

地点写在动作名里。技能数量 **不随 UI 改版而合并**。

## 串联（第一次卡关）

```
缺药打不过林缘 → 溪钓虾、野拾苔 → 炼药 → 再讨伐
```
