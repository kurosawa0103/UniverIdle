# 产品与玩法

> 更新：2026-09-01 · 平台与简化玩法见 [决策记录](../决策记录.md)

## 定位

| 项 | 内容 |
|----|------|
| 类型 | Melvor 式挂机增量 |
| 题材 | 剑与魔法异世界；宇宙 = 坠星、位面、虚空（魔法解释，非科幻） |
| 舞台 | **坠星谷 · 萤溪村**（一颗星砸出的谷，溪水夜里微光） |
| 平台 | Windows PC 首版；手机二期 |

和 Melvor 的差异：**同结构、同简单度**；换地图线（谷→林→坑）、换具体物名、星沙贯穿多配方。

---

## 核心循环

```
左栏选工作 → 点具体动作 → 进度条走完 → 获得材料/经验
缺料就切另一项工作挂一会儿 → 材料够了回来继续
```

**30 秒示例**：钓萤虾 → 熬红药 → 讨伐林缘 → 掉皮 → 锻造护甲 → 进更深区域。

**不要**（v2 已砍）：地图节点、据点建筑、远征配包、学徒并行。

---

## 工作列表（= Melvor 技能栏）

左栏 8 项左右，动作名带地名。数量不随 UI 改版合并。

| 工作 | 低级 | 高级 |
|------|------|------|
| 打猎 | 谷仓 · 赶耗子 | 狼 → 星蚀兽 → 龙 |
| 伐木 | 村外 · 砍枯枝 | 黑林 · 伐橡木 → 逆光木 |
| 溪钓 | 萤溪 · 钓萤虾 | 鳟鱼 → 坑底 · 赤尾鳗 |
| 野拾 | 萤苔、淘星沙 | 逆光木等 |
| 掘矿 | 矮洞 · 挖铜 | 温铁、星髓 |
| 炼药 | 红药水 | 抗热药 |
| 锻造 | 铜刀、皮甲 | 传说装 |
| 讨伐 | 林缘 | 坠星坑、龙窟 |

**第一次卡关范例**：打不过林缘 → 溪钓虾 + 野拾苔 → 炼药 → 再讨伐。

## 坠星谷成长线（落差感）

| 阶段 | 地点 | 在干嘛 |
|------|------|--------|
| 开局 | 萤溪、矮洞 | 耗子、星沙、萤虾、苔、铜矿 |
| 出村 | 黑松林 | 猎狼、松脂、橡木 |
| 进山 | 坠星坑外圈 | 温铁、星蚀狼 |
| 进坑 | 坑深处 | 守坑兽、逆光木 |
| 坑底 | 星髓熔潭 | 钓赤尾鳗 |
| 终局 | 坑底裂隙 | 古龙幼体 / 星骸守卫 |

一句话旅程：*小时候在萤溪淘星沙、钓小虾；后来在坠星坑底烫潭里钓赤尾鳗。*

宇宙只在 **最后几个区域和稀有配方** 出现，前期全是接地气奇幻名词。

## MVP 目标

30 分钟～2 小时可玩闭环（具体技能数 [待确认](03-待定.md)）。

| 要有 | 先不做 |
|------|--------|
| 5～7 项工作、每项若干动作 | 宠物、公会、多章节剧情 |
| 1 条主动作队列 | 精通等深度 Meta |
| 串联：虾→药→狼 | Mod、云存档 |
| 本地存档 + 离线收益 | v2 远征/建筑 |

建议终点情绪：萤溪村 → 黑松林，钩子「坠星坑外圈有红眼狼」。
