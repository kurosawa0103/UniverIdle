# 产品与玩法



> 更新：2026-09-01 · 平台与简化玩法见 [决策记录](../决策记录.md)



## 定位



| 项 | 内容 |

|----|------|

| 类型 | Melvor 式挂机增量 + 异世界修行 |

| 题材 | 剑与魔法异世界；宇宙 = 坠星、位面、虚空（魔法解释，非科幻） |

| 舞台 | **坠星谷 · 萤溪村**（一颗星砸出的谷，溪水夜里微光） |

| 平台 | Windows PC 首版；手机二期 |



操作节奏与 Melvor 同级简单；差异在 **有趣的工作设计**（动作名、递进、产线去向），见下文。



---



## 核心循环



```

左栏选工作 → 点具体动作 → 进度条走完 → 获得材料/经验

缺料就切另一项工作挂一会儿 → 材料够了回来继续

```



**不要**（v2 已砍）：地图节点、据点建筑、远征配包、学徒并行、头衔系统。

## 拾荒（首个工作）

同一项工作，按 **场景** 分动作。**拾荒等级**解锁新地区；**地区熟练度**在各场景独立积累。

| 场景（解锁等级） | 子地点解锁阶梯 | 特色 |
|------------------|----------------|------|
| 村口 Lv.1 | 二狗家 1 → 柴房 2 → 岔路口 3 → 老井 4 → 村长家 5 | 破布、空瓶入门 |
| 黑松林 Lv.10 | 林间小道 10 → 老松树 11 → 神龛 12 → 猎人小屋 13 → 林溪 14 → 盗贼窝 15 | 药草芽、护符 |
| 冒险者旧道 Lv.20 | 废弃营地 20 → 马车驿站 21 → 断桥边 22 | 星尘碎屑、旧护符 |

**后续可加热门场景**（未做）：药铺巷、祠堂台阶、萤溪桥头、客栈后院。

物品见 [玩法-拾荒](../知识库/模块/玩法-拾荒.md)。

萤溪村 → 黑松林 → 坠星坑外 → 坑底；宇宙材料 **后期** 才常见。
