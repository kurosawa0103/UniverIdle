## 产品与 MVP

| 项 | 选项 / 说明 | 倾向 |
|----|-------------|------|
| MVP 技能数 | C1：~4 工作 + 简单战斗；C2：仅采集制作；C3：含地牢/精通 | **C1** |
| 工作栏命名 | 「工作」vs「技能」 | 未定 |
| 地点表达 | 动作名带地名（萤溪·钓虾）vs 讨伐单独选区 | 未定 |
| 星尘 | 是否作多配方公共材料（零机制成本） | 倾向保留 |

## 战斗

- 结算方式：回合 / 攻速计时 / 纯数值
- MVP 区域：1 个奇幻区（如林缘）
- 敌人与掉落、死亡/食物/药水是否保留
- 装备槽与属性（物理/魔法分轨即可）

区域分层：主线奇幻（MVP）→ 进阶奇幻 → 宇宙点缀（坠星坑、虚空，后期）

## 题材与文案

Melvor 式 **奇幻百科/图鉴** 气质合适。候选（可多选）：

| 方案 | 一句话 |
|------|--------|
| **A 万物图鉴** | 公会/学院编纂的百科条目 |
| **C 旅者手账** | 冒险者日记，宇宙作偶发惊奇 |
| **D 典载+野传** | 官方记载 vs 酒馆传说（重要条目双轨） |
| **E 残卷秘典** | 古代魔法书边玩边拼 |

推荐组合：**A+C** 或 **A only**（MVP 最省事）。  
不做科幻终端 / 星舰 HUD。
