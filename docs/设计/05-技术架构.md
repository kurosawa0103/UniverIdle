# 技术架构

> 状态：**部分已确认** · 最后更新：2026-09-01

## 已确认：平台路线

| 阶段 | 平台 | 说明 |
|------|------|------|
| MVP | **Windows PC** | 首版唯一目标平台 |
| 二期 | Android → iOS | PC 稳定后再适配移动端 UI 与出包 |

### PC 首版技术约定（草案）

- **UI**：以 PC 窗口为主设计；Canvas Scaler 支持窗口缩放
- **输入**：鼠标点击为主
- **存档**：`Application.persistentDataPath` + JSON（或同类格式）
- **离线时间**：存 `lastSaveUtc`，恢复时用 `DateTime.UtcNow` 差值计算
- **架构**：玩法逻辑与 UI 分离，便于二期移植手机

### 二期移动端（届时再定）

- 竖屏布局、触控热区、Safe Area、切后台存档策略
- Android 优先，iOS 需开发者账号与审核流程
