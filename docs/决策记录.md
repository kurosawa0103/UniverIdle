## 2026-09-01 — 梳理核心玩法循环

- **决策方向**：核心学 Melvor 的 **多工作列表 + 互相串联**，不是只换题材皮
- **三阶段**：入门小循环 → 多工作规划 → 终局推图/毕业/奇观
- **文档**：见 [核心玩法](设计/08-核心玩法.md)
- **状态**：草案，待确认 MVP 工作数量

## 2026-09-01 — 成长体验：要具体、不要抽象

- **决策方向**：拒绝管理局/权限/尺度等抽象壳；采用 **具体地点 + 具体物品 + 具体动作**（如淘星沙、钓萤虾、剥史莱姆胶）
- **候选方案**：A 地下城门口镇 / **B 坠星谷（倾向）** / C 碎岛链
- **状态**：讨论中，待用户确认 A/B/C

## 2026-09-01 — 题材权重：剑与魔法为主，宇宙为点缀

- **决策**：主舞台为 **剑与魔法异世界**；宇宙/多位面/坠星等仅作背景点缀与后期稀有内容，不做星际科幻主线
- **原因**：玩家体感应接近奇幻放置（Melvor 气质），「Univer」通过无尽大陆与位面之外体现，而非星舰与太空探索
- **影响**：技能命名偏采矿/锻造/炼金；叙述方案倾向图鉴/手账而非科幻终端
- **状态**：已确认

## 2026-09-01 — 首发平台：先做 PC，手机二期

- **决策**：MVP 仅 **Windows PC**；移动端（Android / iOS）放在二期
- **原因**：先集中验证玩法与平衡，避免双端 UI 分散精力；长线仍可做手机
- **预留**：玩法与 UI 分离、存档与离线时间平台无关，降低二期移植成本
- **状态**：已确认（由原「双端同步」调整）

## 2026-09-01 — 题材：宇宙 × 剑与魔法异世界合体

- **决策**：游戏世界观为 **宇宙尺度 + 剑与魔法异世界** 的融合风格，而非纯科幻或纯奇幻
- **表现方向**：星域/位面/异世界大陆并存；魔法与科技（或星术/炼金等）可共存、互相转化
- **原因**：兼顾「Univer」的宇宙感与 Melvor 式奇幻技能链的熟悉感，形成差异化题材
- **状态**：已确认
