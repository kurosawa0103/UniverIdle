## 现行决策（2026-09-01）

| 领域 | 决策 |
|------|------|
| **玩法** | Melvor 级简单：左栏工作 → 点动作 → 一条进度挂机 → 产线串联；**不要**地图据点、远征、学徒并行（v2 已砍） |
| **题材** | 剑与魔法异世界为主；宇宙/位面仅点缀；MVP 舞台 **坠星谷 · 萤溪村**（具体物品名，拒绝抽象管理局壳） |
| **平台** | **PC 优先**（Windows）；手机二期；玩法与 UI 分离、存档用 `persistentDataPath` |
| **UI 布局** | 对齐 [主界面-概念.html](设计/概念图/主界面-概念.html)：左技能 / 中横幅+动作卡+进度 / 右详情 / 底物品 |
| **UI 实现** | Unity 用 **纯色块**占位（不加载贴图）；交互与分区跟概念图，视觉插画二期再接 |
| **文档** | `docs/` 中文文件名；设计写「做什么」，[知识库](知识库/说明.md) 写「已怎么做」 |
