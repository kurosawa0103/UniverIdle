# 玩法-挖矿

> 状态：**已实现** · 更新：2026-09-01

## 概述

- 工作 id：`mining`（**挖矿**）
- 地点：**坠星矿洞**
- 挂机一段时间后 **必定** 获得对应矿石（`loot.chance = 1`，同砍树）
- **挖矿等级**解锁新矿脉；各矿脉 **熟练度** 独立积累

## 矿脉与掉落

| 矿脉 | 动作 | 解锁（挖矿等级） | 耗时 | 掉落 |
|------|------|------------------|------|------|
| 铜矿脉 | 开采 | Lv.1 | 4.5 秒 | 铜矿石 |
| 锡矿脉 | 开采 | Lv.3 | 5.5 秒 | 锡矿石 |
| 铁矿层 | 开采 | Lv.6 | 7 秒 | 铁矿石 |
| 陨铁矿 | 开采 | Lv.10 | 10 秒 | 陨铁矿石 |

矿石定义在 `items.json`：`copper_ore`、`tin_ore`、`iron_ore`、`meteor_ore`。

## 配表

独立工作簿 **mining.xlsx / mining.json**；Sheet：`works` / `work_levels`（挖矿总等级）/ `action_levels`（各矿脉动作独立熟练度）/ `actions` / `loot`。等级经验表 1–160，有表时优先于公式；末级封顶。

改表后：**UniverIdle → 导表工具** 勾选挖矿相关 Sheet 导出。

Excel / JSON 路径与字段说明见 [配置-配表](配置-配表.md)。
