# 配置-配表

> 状态：**多 Excel + 多 JSON** · 更新：2026-09-04

## 工作流

```
编辑 items.xlsx / scavenge.xlsx / woodcutting.xlsx / mining.xlsx / monster_explore.xlsx → 导表工具勾选 → 五个 JSON → 运行时分别加载
```

| 源（Excel） | 产物（JSON） | 运行时 |
|-------------|--------------|--------|
| `items.xlsx` | `items.json` | 全游戏道具 |
| `scavenge.xlsx` | `scavenge.json` | 拾荒 works / 等级表 / actions / loot |
| `woodcutting.xlsx` | `woodcutting.json` | 砍树 works / 等级表 / actions / loot |
| `mining.xlsx` | `mining.json` | 挖矿 works / 等级表 / actions / loot |
| `monster_explore.xlsx` | `monster_explore.json` | 魔物探索 works / 等级表 / actions / loot |

`loot.itemId` 必须对应 `items.json` 里的 `id`；导出时会校验。

**背包容量**不走 Excel：直接改 `Assets/StreamingAssets/Game/inventory.json`，见 [UI-背包](UI-背包.md)。

**部分导出**：只写勾选表对应的 JSON；未勾选的段保留原文件内容。

| 菜单 | 作用 |
|------|------|
| **UniverIdle → 导表工具...** | 唯一入口：勾选、生成 Excel、导出 JSON |

## items.xlsx · items

一张表即可。用 **category** 列分类，Excel 开筛选就能按类型看；不要拆成多份道具表（掉落仍要一份 id 对照）。

| id | name | category | icon | description |

| category | 含义 |
|----------|------|
| `junk` | 杂物（拾荒入门料） |
| `wood` | 原木 |
| `ore` | 矿石 |
| `monster` | 魔物素材 |
| `herb` | 药草 |
| `tool` | 工具（陷阱等） |
| `relic` | 遗物（护符、星尘） |
| `system` | 系统占位（`_empty`） |

背包筛选以后走这列；配方仍只认 `id`。

## 工作簿共用 Sheet

每个玩法 xlsx（拾荒 / 砍树 / 挖矿 / 魔物探索）含：

| Sheet | JSON 字段 | 说明 |
|-------|-----------|------|
| `works` | `works` | 工作参数；`xpBase` 等公式仅作**无等级表时**兜底 |
| `work_levels` | `workLevels` | **总等级**（拾荒/砍树…）：`level` + `xp`；配 **1–160** |
| `action_levels` | `actionLevels` | **动作熟练度**共用曲线：进度按每条 `actionId` 独立累计 |
| `actions` | `actions` | 动作 |
| `loot` | （嵌在 actions） | 掉落 |

`work_levels` / `action_levels`：第 1 行中文、第 2 行英文 `level` | `xp`。有非空表时运行时**优先查表**；到达表内最高级后**不再升级**（末级 `xp` 填 0）。预填曲线约为 `xpBase + xpPerLevel×L + 0.9×L²`（比纯线性更陡）。

## monster_explore.xlsx · works / levels / actions / loot

见 [玩法-魔物探索](玩法-魔物探索.md)。`actions` 表新增 `costItemId`、`costAmount`；`loot` 同拾荒。

**loot 表**：

| actionId | itemId | #itemName | chance | min | max |

`#itemName` 为策划对照用中文名，**不导出**；从 JSON 生成 Excel 时会按 `items` 自动填。扩展列须以 `#` 开头。

每张表：**第 1 行中文说明，第 2 行英文字段名**（导表读第 2 行）。

`works` 字段：`id` / `name` / `locationName` / `xpBase` / `xpPerLevel` / `actionXpBase` / `actionXpPerLevel` / `grantWorkXp` / `grantActionXp`（无图标颜色列）。
