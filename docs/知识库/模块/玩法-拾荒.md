# 玩法-拾荒

> 状态：**已实现** · 更新：2026-09-03

## 职责

- 第一个可玩工作：**拾荒**（`scavenge`）
- **拾荒等级**（整项工作）：任意地区挂机都会涨，用于 **解锁新地区**
- **地区熟练度**（每个 sceneId 独立）：只在该地区挂机时涨，显示在动作卡上

## 熟练度（双轨）

| 类型 | 作用 | 显示 |
|------|------|------|
| **拾荒等级** | 解锁地区（`requiredWorkLevel`） | 左栏 `拾荒 Lv.X` + 经验条 |
| **地区熟练度** | 该地区练了多少（暂无额外机制） | 动作卡 `熟练 Lv.X` |

完成一次动作：**同时** +拾荒经验、+该地区经验。

## 场景与子地点

- **场景**（`sceneId` / `sceneName`）：横幅标题，如「村口」；地区熟练度按 `sceneId` 累计。
- **子地点**（`spotName`）：动作卡标题，如「老王家」「岔路口」；同一场景下可有多条 `actions` 行共享 `sceneId`。
- 横幅 **Tags**：拾荒用地图节点显隐切换地区（节点填 `sceneId`）；运行时 Tag 条是给未绑地图的工作用的。

## 地区与子地点解锁（拾荒等级）

- **场景 Tag**：该场景内子地点 `requiredWorkLevel` 的**最小值**达到即可点开（`WorkSceneGroup.MinRequiredWorkLevel`）。
- **子地点动作卡**：每条 action 各自配 `requiredWorkLevel`；未达则缩略图黑剪影、不可点，文案「{工作名}等级达到N解锁」。

配表字段：`actions.spotName`、`actions.requiredWorkLevel`、`actions.description`（在 `scavenge.xlsx` → `actions` 或 `scavenge.json` 维护）。

工作参数在 **works** 表：`xpBase`、`xpPerLevel`、`sceneXpBase`、`sceneXpPerLevel` 等，见 [配置-配表](配置-配表.md)。

## 代码入口

| 类型 | 符号 |
|------|------|
| 解锁规则 | `SceneProgressRules.IsRegionUnlocked` |
| 场景分组 | `GameContent.GetSceneGroupsForWork` |
| 工作 id | `GameContent.WorkScavengeId`（`scavenge`） |
