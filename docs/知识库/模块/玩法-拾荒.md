# 玩法-拾荒

> 状态：**已实现** · 更新：2026-09-04

## 职责

- 第一个可玩工作：**拾荒**（`scavenge`）
- **拾荒总等级**（整项工作）：任意子地点挂机都会涨，用于 **解锁新地区 / 子地点**
- **动作熟练度**（每个 actionId 独立）：只在该动作挂机时涨，显示在对应动作卡上

## 熟练度（双轨）

| 类型 | 作用 | 显示 |
|------|------|------|
| **拾荒总等级** | 解锁地区与子地点（`requiredWorkLevel`） | 左栏 `拾荒 Lv.X` + 经验条；表 `work_levels` |
| **动作熟练度** | 该子地点练了多少（暂无额外机制） | 动作卡 `Lv.X` + 分档图标（1–30 铜 / 31–70 银 / 71+ 金）；表 `action_levels` |

完成一次动作：**同时** +总等级经验、+该动作熟练度经验。升级所需经验见 `work_levels` / `action_levels`（1–160，末级封顶）。

## 场景与子地点

- **场景**（`sceneId` / `sceneName`）：横幅标题，如「村口」；地图节点显隐仍按场景。
- **子地点**（`spotName` / action）：动作卡标题，如「老王家」「岔路口」；**熟练度按 action 独立**，不再按 scene 共享。
- **切换地区**：拾荒用**地图节点显隐**（节点填 `sceneId`）。运行时横幅 Tag 条只给未绑地图的工作（`sceneId` 空）用，拾荒不用。

## 地区与子地点解锁（拾荒总等级）

- **场景解锁**：该场景内子地点 `requiredWorkLevel` 的**最小值**达到即可进入该地图节点（`WorkSceneGroup.MinRequiredWorkLevel`）。
- **子地点动作卡**：每条 action 各自配 `requiredWorkLevel`；未达则缩略图黑剪影、不可点，文案「{工作名}总等级达到N解锁」。

|------------------|--------|----------|

配表字段：`actions.spotName`、`actions.requiredWorkLevel`、`actions.description`（在 `scavenge.xlsx` → `actions` 或 `scavenge.json` 维护）。

工作参数在 **works** 表：`xpBase`、`xpPerLevel`、`sceneXpBase`、`sceneXpPerLevel` 等（无等级表时兜底；后两列实际用于动作熟练度公式）；**总等级 / 动作熟练度**优先读 `work_levels` / `action_levels`，见 [配置-配表](配置-配表.md)。

## 代码入口

| 类型 | 符号 |
|------|------|
| 拾荒 Hub | `ScavengeHubView`（工作根，持有并分发 `ScavengeDetailView`） |
| 地图 Center | `StandardWorkCenterView`（节点 `sceneId`） |
| 拾荒详情 | `ScavengeDetailView`（仅拾荒；含 `Btn_工作`） |
| 解锁规则 | `SceneProgressRules.IsRegionUnlocked`（看总等级） |
| 动作熟练度 | `PlayerState.GetActionMastery` / `AddActionXp` |
| 场景分组 | `GameContent.GetSceneGroupsForWork` |
| 工作 id | `GameContent.WorkScavengeId`（`scavenge`） |

## 已知限制

- 动作熟练度暂无掉落/速度加成（可后续加）
- 等级上限由 `work_levels` / `action_levels` 表末级决定（当前 160）
- 旧存档里的地区熟练度（`scenes`）不再读取；熟练度按动作重新累计
- 存档见 [SAVE-存档](SAVE-存档.md)
