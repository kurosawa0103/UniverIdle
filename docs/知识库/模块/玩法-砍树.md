# 玩法-砍树

> 状态：**已实现** · 更新：2026-09-03

## 概述

- 第二个可玩工作：**砍树**（`woodcutting`）
- 界面是 **纯动作列表**（`ActionListWorkCenterView`）：不绑地图、不切 scene；点卡开始，再点同一张停止
- 右侧详情用 **`WorkActionDetailView`**（标题/正文/掉落预览/获得提示），与拾荒 `ScavengeDetailView` 分离，无「开始拾荒」按钮
- 挂机一段时间后 **必定** 获得对应树种的原木（`loot.chance = 1`）
- **砍树等级**解锁新树种；未达等级的动作卡缩略图为黑剪影、不可点，显示「砍树等级达到N解锁」；表内 `sceneId` 只用于各树种熟练度 XP，界面不展示；动作卡熟练度图标同拾荒分档（1–30 铜 / 31–70 银 / 71+ 金）

## 树种与掉落

| 树种 | 动作 | 解锁（砍树等级） | 耗时 | 掉落 |
|------|------|------------------|------|------|
| 短松 | 伐木 | Lv.1 | 4 秒 | 松木 |
| 白桦 | 伐木 | Lv.3 | 5 秒 | 桦木 |
| 橡树 | 伐木 | Lv.6 | 6.5 秒 | 橡木 |
| 胡桃 | 伐木 | Lv.8 | 8 秒 | 胡桃木 |
| 铁木 | 伐木 | Lv.10 | 9 秒 | 铁木 |

原木定义在 `items.json`：`pine_log`、`birch_log`、`oak_log`、`walnut_log`、`ironwood_log`。

## 配表

砍树使用 **独立工作簿**（与拾荒分开）。表结构同拾荒：`works` / `actions` / `loot` 三个 Sheet。

改表后：**UniverIdle → 导表工具** 勾选砍树相关 Sheet 导出。

Excel / JSON 路径与字段说明见 [配置-配表](配置-配表.md)。
