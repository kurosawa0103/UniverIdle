# 玩法-砍树

> 状态：**已实现** · 更新：2026-09-04

## 概述

- 第二个可玩工作：**砍树**（`woodcutting`）
- 界面与拾荒相同：**地图式**（`WorkMapHubView` + 地图节点 `StandardWorkCenterView` + `WorkRunDetailView` 开工按钮）；点卡选动作，详情按钮开始/停止
- 挂机一段时间后 **必定** 获得对应树种的原木（`loot.chance = 1`）
- **砍树总等级**解锁新树种；未达等级的动作卡缩略图为黑剪影、不可点，显示「砍树总等级达到N解锁」；各树种动作**独立熟练度**；动作卡熟练度图标同拾荒分档（1–30 铜 / 31–70 银 / 71+ 金）

## 代码入口

| 类型 | 符号 |
|------|------|
| 地图 Hub | `WorkMapHubView`（与拾荒共用） |
| 地图 Center | `StandardWorkCenterView`（节点 `sceneId`） |
| 开工详情 | `WorkRunDetailView` |
| 工作 id | `woodcutting`（`GameContent` / 配表） |

> 若 Resources 里 `WorkView_woodcutting` 仍挂 `ActionListWorkCenterView`，属预制体未跟上脚本/文档，以地图式为准手配。

## 树种与掉落

| 树种 | 动作 | 解锁（砍树等级） | 耗时 | 掉落 |
|------|------|------------------|------|------|
| 短松 | 伐木 | Lv.1 | 4 秒 | 松木 |
| 白桦 | 伐木 | Lv.3 | 5 秒 | 桦木 |
| 橡树 | 伐木 | Lv.6 | 6.5 秒 | 橡木 |
| 胡桃 | 伐木 | Lv.8 | 8 秒 | 胡桃木 |
| 铁木 | 伐木 | Lv.10 | 9 秒 | 铁木 |

原木定义在 `items.json`：`pine_log`、`birch_log`、`oak_log`、`walnut_log`、`ironwood_log`。

## 配表

砍树使用 **独立工作簿**（与拾荒分开）。Sheet：`works` / `work_levels`（砍树总等级）/ `action_levels`（各树种动作独立熟练度）/ `actions` / `loot`。等级经验表 1–160，有表时优先于 works 公式；末级封顶。

改表后：**UniverIdle → 导表工具** 勾选砍树相关 Sheet 导出。

Excel / JSON 路径与字段说明见 [配置-配表](配置-配表.md)。
