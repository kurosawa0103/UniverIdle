# 玩法-魔物探索

> 状态：**已实现** · 更新：2026-09-01

## 概述

- 工作 id：`monster_explore`（**魔物探索**）
- 按 **场景** 挂机：每次开始前 **消耗陷阱道具**，完成后按概率 **随机掉落** 魔物素材
- **探索等级**解锁新场景；各场景 **熟练度** 独立积累

## 场景与消耗

| 场景 | 解锁 | 耗时 | 每次消耗 | 特色掉落 |
|------|------|------|----------|----------|
| 林缘哨道 | Lv.1 | 5s | 小陷阱 ×1 | 史莱姆凝胶 |
| 溪谷岔路 | Lv.3 | 6s | 小陷阱 ×1 | 兽皮、浆液 |
| 旧矿道口 | Lv.6 | 7.5s | 大陷阱 ×1 | 兽牙、魔核 |
| 坠星裂隙 | Lv.10 | 10s | 大陷阱 ×2 | 魔核、星尘碎屑 |

陷阱与素材定义在 `items.json`：`small_trap`、`large_trap` 等。

材料不足时 **无法开始**，挂机中材料用尽会 **自动停止**。

## 配表

独立工作簿 **monster_explore.xlsx / monster_explore.json**：

| Sheet | 说明 |
|-------|------|
| works | 工作参数 |
| actions | 场景动作；`costItemId` + `costAmount` 为每次消耗 |
| loot | 随机掉落（同拾荒 loot 表） |

改表后：**UniverIdle → 导表工具** 勾选魔物探索相关 Sheet 导出。

字段说明见 [配置-配表](配置-配表.md)。
